# Proyecto-SQL-Caso_Hotel_DataAndino-CLL
Se aplicó limpieza de datos, funciones de fecha y lógica condicional (CASE WHEN, CEIL) para modelar plazos y segmentar riesgos de cancelación. Mediante agregaciones avanzadas, se cuantificaron pérdidas. Finalmente, cruces relacionales (JOINs) con tablas auxiliares auditaron la integridad operativa, fundamentando la necesidad de reestructurar las políticas de depósitos y penalizaciones según el comportamiento del cliente.
